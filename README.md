# 青椒简历

免登录的简历编辑器，使用 Next.js 16、React 19 和 Tailwind CSS 4。

## 使用

- 在“简历”中新建、重命名、复制或删除简历。
- 列表显示实际简历缩略预览，按最近更新排列。
- 编辑器支持模块排序、显隐、自定义内容、头像裁剪和三种模板。
- “排版”分别调整姓名、标题和正文字号，以及行距、段落、经历和模块间距。字号显示为 pt，存储仍用 CSS px；重置恢复排版默认值并清除模块单独样式，保留技能标签及栏位设置。
- 经典模板为紧凑单栏；分栏模板默认把基本信息、教育和技能放侧栏，其余放正文，可调整每个模块的位置；每栏保持模块相对顺序。只有一栏有内容时使用全宽，切换其他模板仍按原模块顺序显示。
- 模块栏可选择“另起一页”，让该模块在打印时从新页开始；再次点击取消。隐藏或空模块不产生空白页，设置随简历、历史和备份保存。
- 技术模板使用项目侧线和技能分组，清理原卡片边框及大块留白。单栏头像移到页头右侧，并保持原裁剪比例。
- “密度”提供紧凑、标准、宽松，只调整行距和段落、经历、模块间距；应用时清除模块单独间距，保留单独字号。当前密度按实际设置判断，手动调整后显示“自定义”。
- 教育、工作和项目卡片可收起，收起时保留条目名称与操作入口；收起状态只在当前编辑会话内生效，不改变简历内容和打印。
- 桌面端可收起管理栏以扩大编辑与预览空间；预览中可见模块有“编辑”入口，选择后切到对应模块并回到编辑面板顶部。移动端管理视图沿用底部导航。
- 教育、工作和项目支持上移、下移、复制和删除，操作常显。复制放在原条目后，使用独立 ID，保留日期、成果格式及链接；移动与复制可撤销并自动保存。
- 工作、项目和自定义内容提供“加粗、列表、链接”。格式操作进入会话撤销，正文继续保存纯文本；文本导入保留描述中的列表、加粗和命名链接。
- 移动端选择模块后进入编辑；隐藏面板退出键盘访问，底部导航显示当前视图。
- 预览按容器实际宽度适配，手动缩放在窗口变化后保留；点击“适配宽度”恢复自动适配。正文可选择，空白处可用鼠标拖拽，触屏使用原生滚动。
- 预览工具在移动端常显，桌面悬停或键盘聚焦时显示；技能标签圆角支持 0。
- 编辑器提供撤销与重做，保留最近 30 步会话操作；同一输入框 500 毫秒内的连续修改合并。刷新或读取最新内容后清空会话操作；输入框内仍使用原生文本快捷键。
- 删除模块会清理对应正文和独立样式，可用撤销恢复，或通过“添加模块”重新添加标准模块。项目可填写链接。
- 头像支持裁剪和删除。换图、取消或离开后旧操作不再回写；裁剪输出 PNG，保留透明背景。
- 内容保存在当前浏览器，编辑后自动保存。撤销回已保存内容时重新核对存储并更新状态；存在外部冲突时仍显示失败。保存失败时保留当前页面，并下载备份。
- 其他标签页修改或删除同一份简历时，会提示并保留当前编辑内容。可另存副本、下载备份，或确认后读取最新内容。
- JSON 和文本导入先展示预览，确认后替换当前内容。导入、AI 应用和恢复历史前保存快照，最多保留十份。
- 文本导入会重建标准模块，保留模板及排版设置，旧自定义内容不会混入新内容。
- 文本解析区分章节和条目标题，保留正文年份、项目链接及含斜杠的技能；不支持的章节列为未识别内容。切换文件、编辑文本和关闭导入会取消旧文件读取。
- “设置”提供全部简历备份与恢复。恢复会新建简历，不覆盖现有内容；备份包含版本历史，不包含密钥。
- 旧版默认简历尚未登记时，列表会先校验再加入，已有其他简历也会保留。全部备份直接包含未登记的旧正文和历史，导出不写入存储；数据损坏时提示下载原始备份。
- 恢复前先核对文件、简历名称和历史数量，再确认新增；取消、换文件或清空会中止旧读取。空备份不写入。
- 外观控件同步其他标签页的修改和清空；设置损坏时停止写入，支持重试读取和原始备份。

## 正文格式

支持 `**重点**`、以 `- `、`* `、`+ `、`• ` 开头的无序列表、数字加点或括号的有序列表，以及 `[文字](https://example.com)`。普通段落保持可见，不执行 HTML；不提供完整 Markdown 或嵌套列表。链接只支持 HTTP/HTTPS，工具栏会编码地址中的括号。`Ctrl/Cmd+B` 加粗，`Ctrl/Cmd+K` 插入链接；多行加粗保留列表符号，链接确认前会核对原文，取消不修改内容。

预览、模板、缩略图和打印共用正文渲染，缩略图链接不可交互。新排版字段缺失时补默认值，已有字体、字号、行距和模块单独样式保留。新默认行距为 1.5，模块和经历间距为 20px、12px。

## 打印 PDF

点击“打印简历”，在系统打印窗口选择“保存为 PDF”。使用 A4 纵向；可关闭浏览器页眉页脚，并启用背景图形以保留模板颜色。

PDF 使用文本排版。编辑器显示换页位置和预估页数；手动换页后的预览不画连续页边界，最终分页和文件名以打印窗口为准。取消打印不会显示保存成功。

## AI 设置

在“AI 设置”填写服务地址、模型和自己的密钥。仅支持 OpenAI-compatible Chat Completions 协议。

服务地址示例为 `https://example.com/v1`。浏览器会直接向服务商的 `/chat/completions` 发送请求，服务必须允许本站来源、`Authorization` 和 `Content-Type` 的跨域请求。不提供服务器代理；跨域不兼容时仍可使用编辑、保存和打印。

地址和模型可保存到本机。密钥只存在于当前页面会话内存中，刷新后需重新输入；不会进入备份或服务器配置。历史版本中持久保存的密钥会被清理。

“测试连接”会发送真实的最小请求。业务请求可取消，超时为 60 秒。AI 修改先预览，确认后应用；原文变化时需重新生成。整份分析仅使用可见模块，默认排除联系方式和头像。生成描述需要先填写实际职责或成果。

AI 建议可编辑后应用或直接复制；原文变化时仅允许复制建议。分析弹窗可取消请求，关闭弹窗也会取消请求。复制失败时会选中文本供手动复制，不显示已复制。

## 本地开发

```bash
npm install
npm run dev
```

访问 `http://localhost:3000/qingjiao_resume/`。执行安装前请遵循本机工具安装约定。

现有生产脚本与 Docker 配置保留；本轮编码未运行安装、测试、构建、浏览器验收或简历 AI 请求，也未修改 CI、Docker 或托管配置。

## 数据边界

简历数据属于当前浏览器及站点来源。清除浏览器数据、更换设备或更换站点来源不会自动迁移简历，请使用备份。损坏数据可通过“原始备份”下载，应用不会以空白内容自动覆盖。

当前仍保留 Node standalone 输出；既有 GitHub Pages 工作流使用 `out` 目录，两者的部署配置不一致尚未在本轮处理。
